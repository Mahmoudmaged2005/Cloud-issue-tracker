# Cloud Issue Tracker

Starter application used across the Cloud Computing and Cloud Security
labs.

## Running and deploying

The frontend is a static site. The Express API stores issues in Neon Postgres.
See [backend/README.md](./backend/README.md) for local setup, database
preparation, and the Vercel and Cloudflare deployment steps.
